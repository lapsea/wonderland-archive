## 一、风格锚点

### 1.1 一句话定义

**彩色古典幻想插画 × 超现实剧场拼贴 × 英式编辑海报设计**

完整水粉、水彩和彩铅色彩，辅以剪纸、织物、雕花黄铜与少量细墨线。画面像一本被翻阅过无数次的手工书——有磨损、有色差、有手写的痕迹。

### 1.2 三项不可动摇的风格法则

| 法则 | 说明 | 违规示例 |
|------|------|----------|
| **55:45 色域法则** | 每张画面中主色调占 55%，其余色彩共占 45%，确保画面有明确的情绪归属 | 50:50 平均分配 → 画面失去情绪方向 |
| **材质可见法则** | 纸纹、水彩笔触或拼贴边缘至少一项必须在画面中可感知 | 纯矢量平滑渐变 → 数字味 |
| **非对称重量法则** | 视觉重心偏移中线至少 10%，拒绝教科书式居中构图 | 人物正中、地平线对半 → 呆板 |

## 三、三层视觉语言系统

| 层级 | 风格 | 媒介感 | 用途 |
|------|------|--------|------|
| **A 层：场景底图** | 水彩薄涂 + 拼贴肌理 | 旧书环衬、褪色地图 | 地图底图、全景场景 |
| **B 层：角色与道具** | 不透明水粉 + 墨线勾边 | 铜版画插图、标本卡片 | 视差角色、人物立绘 |
| **C 层：UI 与文字** | 凸版印刷 + 黄铜装饰 | 烫金书脊、档案标签 | 按钮、面板、标签 |

三层的材质感从 A 到 C 递减——场景最"湿"（水彩渗透），UI 最"干"（油墨压印）。

## 五、资产生产规范

### 5.1 AI 生成通用 Prompt 模板

```
[风格锚定] 彩色古典幻想插画风格，水粉与水彩混合技法，
英式复古拼贴质感，19世纪铜版画印刷肌理

[画面要求] 完整水粉/水彩/彩铅色彩，纸张纹理可感知，
非对称构图，暖色主导/冷色主导（依场景情绪）

[技术参数] 4:5 或 3:4 比例，300dpi，WebP 输出，
保留水彩边缘渗透效果

[叙事语境] {具体角色/场景/道具描述}

[禁止项] 禁止扁平矢量风格、禁止光滑渐变、禁止对称居中构图、
禁止纯白背景、禁止AI感的过度柔焦和人脸塑料质感
```

### 5.2 角色立绘规范

- **A 层（人物身体）**：不透明水粉上色，墨线勾边，有轻微纸张纹理叠加
- **B 层（装饰与道具）**：拼贴质感——怀表链用烫金线条，帽子用织物纹理
- **C 层（阴影）**：水彩薄涂，边缘渗透入纸面，不做硬阴影
- **裁切**：人物需完整包含从头到脚的全身像，对象居中偏右 5%，底部留白不超过 2%
- **文件命名**：`{角色英文名}.png`，PNG 格式，透明背景

### 5.3 场景底图规范

- **地图**：水彩薄涂地形 + 拼贴标注，像一份被折叠过很多次的旅行地图
- **全景场景**（如茶会长桌）：横向宽幅，手绘感笔触，多屏拼接时笔触需连续
- **卡片**：350×490px 基础画布，主体占 75%，四边各留 12.5% 白边

### 5.4 纸张纹理与材料

全局使用的材料纹理文件：

| 文件 | 尺寸 | 用途 |
|------|------|------|
| `warm-paper.webp` | — | 暖色调纸张，用于所有 `.paper-panel` 的背景叠加 |
| `timeline-background.jpg` | — | 时间线地图的水彩底色 |

CSS 中的纹理模拟（不需要实际文件）：
- 场景内边框：`border: 1px solid rgba(..., 0.22)` + `border-radius: 22px`
- 纸张阴影：`box-shadow: 0 18px 50px var(--shadow), inset 0 0 32px rgba(118, 89, 44, 0.08)`
- 素描线：`repeating-linear-gradient(...)` 模拟纸面纤维纹理

## 八、设计禁忌清单

- **禁止** 纯黑（#000000）或纯白（#FFFFFF）大面积使用——最暗用 `#071a2f`，最亮用 `#fdf6e8`
- **禁止** 光滑渐变（linear/radial-gradient 无纹理叠加）
- **禁止** AI 生成人脸出现"塑料感"——需叠加纸纹或轻微噪点
- **禁止** 角色对称站立正面——至少 10° 侧转或 5% 偏移
- **禁止** 字体使用系统默认 sans-serif 作为展示字体——展示字体必须为 Georgia / Songti SC
- **禁止** 任何页面出现纯色无纹理背景——每个背景至少包含一道渐变或一层纹理叠加
