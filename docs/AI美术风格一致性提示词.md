# AI 美术风格一致性提示词

生成前请同时提供 1–3 张项目中与目标资产同类型的现有图片作为风格参考；只继承其视觉语言，不照搬构图。

## 通用母提示词

```text
为《爱丽丝梦游仙境：奇境档案馆》创作【画面主题】。严格延续项目现有风格：鲜活的彩色古典英式幻想插画，融合维多利亚时代造型、超现实剧场式拼贴与精致编辑设计；使用水粉、水彩、彩铅和少量细墨线的手绘质感，辅以剪纸、织物、雕花黄铜、丝绒植物、玫瑰、钟表、钥匙孔、扑克牌和棋盘格等奇境元素。画面优雅神秘、华丽但有秩序，主体清晰，层次丰富，具有可探索的前景—中景—远景和统一光线。配色以深森林绿、象牙白、炭黑、古董金为稳定基底，以红桃红、奇境青绿、爱丽丝蓝、梦境紫作鲜明点缀；颜色饱满但不霓虹，只保留轻微纸张、印刷和边缘磨损质感。

禁止：整体棕褐或灰黄滤镜、泛黄古籍扫描感、低饱和脏旧、恐怖阴森、低幼卡通、动漫大眼、照片写实、塑料感 3D、赛博霓虹、毛玻璃 UI、廉价金色、素材随意拼贴、文字、Logo、水印，以及照搬任何影视版角色造型。
```

## 按资产类型追加一句

- **场景图：** `采用宽幅舞台式构图，一个明确视觉中心，强纵深与路径引导，并为网页标题、按钮和交互热点预留低细节安全区。`
- **角色图：** `采用完整彩色古典童话立绘，轮廓清晰、比例略作精致童话化夸张；严格保持既有角色的年龄、脸型、发型、服装结构、主色和标志配件。`
- **档案卡：** `采用红、黑、象牙白、青绿与古董金的英式收藏卡设计，古典标签轮廓、棋盘格和扑克纹样清晰有序，不在图片中生成正式文字。`
- **时间线背景与视差层：** `把八幕旅程组织成一座横向超现实剧场：彩绘景片、剪纸植物、丝绒枝叶、黄铜器物、画框、时钟、棋盘路径和扑克符号共享统一光线与纵深；画面鲜活、华丽但有秩序，并为八个节点保留低细节安全区。不要生成泛黄古籍年表或自然主义风景画。`
- **时间线节点图：** `制作一张可在 220×150px 下清晰识别的彩色幻想章节徽记：一个强视觉中心、2–3 个叙事符号、英式编辑海报式几何构图与大胆留白；使用完整彩色手绘和少量细墨线，不使用整幅铜版排线、棕褐滤镜或普通田园绘本构图。图片内不生成编号、标题、边框和按钮。`

## 一致性使用原则

同一角色继续出图时，必须把该角色现有标准立绘作为身份参考；同一场景系列优先引用对应的现有场景图。每次只改变主题、姿态或镜头，其余风格、角色身份、配色强度和材质保持不变。
