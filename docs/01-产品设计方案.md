7. 保留：柴郡猫失踪暗线（并入"隐藏故事"，终点=柴郡猫迷宫）、13 种交互库、维多利亚手稿美术方向、技术栈。

# 1. 产品定位

## 1.1 互动书名称

**《爱丽丝梦游仙境：奇境档案馆 Alice's Wonderland Archive》**

命名逻辑：采用用户的初步命名。"档案馆"点明产品形态——不是一本书，而是一个可以探索、收集、解谜的奇幻世界数据库。

## 1.2 一句话介绍

> 进入兔子洞，打开一座维多利亚手稿风格的奇境档案馆：沿梦境时间线走完爱丽丝的旅程，在奇境地图上自由探索每一个地点，把遇到的人物、生物、物品与文献一一归档——并解开柴郡猫失踪的隐藏谜团。

## 1.3 核心体验

**一句话概括：它的核心不是复述故事，而是让用户"进入兔子洞"，逐渐发现这个世界。**

双轨体验 + 三层循环：

```
【叙事轨】梦境时间线：7 个事件，线性推进，每个事件 = 故事+插画+动画+小游戏
【探索轨】奇境地图：8 个地点，自由进入，每个地点 = 场景档案+场景卡互动
        两轨互锁：时间线推进解锁新地点；地点探索喂饱档案库与谜题

探索（Explore）  →  发现（Discover）  →  归档（Archive）
 地图/时间线       场景卡、隐藏线索、     档案卡显影 +
 自由漫游         文献、人物隐藏问题     谜题进度推进
      ↑___________________________________|
          归档解锁谜题（密码门）与隐藏故事（柴郡猫迷宫）
```

- **叙事轨**保证任何人都能顺畅走完故事（不会迷路）；
- **探索轨**满足考据与收集欲（每个地点都藏着不在主线里的东西）；
- **解谜层（Metagame）**：馆长柴郡猫失踪了。他把 12 片"笑容碎片"藏在 8 个地点与 3 个隐藏故事里；集齐后可进入**柴郡猫迷宫**，抵达迷宫中心的"第 13 号档案"。

**体验情绪曲线**：好奇（入洞）→ 失控（变大变小）→ 荒诞欢乐（茶会）→ 不安（王后的砍头令）→ 觉醒（审判/撒牌）→ 释然（醒来）。

## 1.4 目标用户

| 用户群 | 占比假设 | 需求 | 对应设计 |
|---|---|---|---|
| 文学/童话爱好者（18–35 岁女性为核心） | 主要 | 有审美、有考据欲的重读体验 | 手稿美术、档案卡考据、原著金句文献 |
| 休闲解谜/收集玩家 | 主要 | 轻量谜题 + 图鉴成就感 | 三大谜题、档案完成度、无失败惩罚 |
| 原著考据党 / 英语文学学习者 | 次要 | 双语文本、注释、创作背景 | 档案卡中英对照、"卡罗尔注释"折叠层 |
| 亲子共读（家长 + 8 岁以上儿童） | 次要（V1.5 发力） | 安全、可读、可共同参与 | 朗读模式、简单模式（后续版本） |

明确**不服务**：硬核游戏玩家（无操作深度）、只想快速读完原著的读者（这不是高效阅读工具）。

## 1.5 与普通电子书的区别

| 维度 | 普通电子书 | 奇境档案馆 |
|---|---|---|
| 阅读单位 | 页 | 地点、事件、档案卡 |
| 用户角色 | 读者 | 档案馆研究员（有自己的档案册） |
| 推进方式 | 翻页 | 时间线推进 + 地图自由漫游 |
| 文本 | 全文线性 | 场景叙事 + 可挖掘的分层档案（卡/文献/注释/金句） |
| 结构 | 单线 | 双轨 + 网状档案 + 隐藏故事 |
| 完成定义 | 读到最后一页 | 档案完成度 100% + 走出柴郡猫迷宫 |
| 重访价值 | 低 | 高（遗漏收集品、分支区域、隐藏故事） |

# 2. 世界观拆解

## 2.1 核心地点（地图 8 节点主链 + 3 隐藏地点）

采用初步想法中的地图主链（8 个地点线性串联，即地图上的"主干道"）：

```
兔子洞 → 下落大厅 → 眼泪池塘 → 毛毛虫森林 → 疯帽子茶会
                                              ↓
                              最终审判庭 ← 槌球场 ← 红桃皇后宫殿
```

| # | 地点 | 原著出处 | 视觉关键词 | 档案馆功能定位 |
|---|---|---|---|---|
| L1 | 兔子洞 | 第1章 | 河岸树洞、无尽竖井、漂浮物 | 入口地点；时间线 E01/E02 所在地 |
| L2 | 下落大厅 | 第1章 | 长廊多门、玻璃桌、小门透光 | 规则教学场；谜题1（变大变小分支）所在地 |
| L3 | 眼泪池塘 | 第2章 | 巨大室内水域、漂浮物 | 渡水场景卡；通往隐藏故事的渡口 |
| L4 | 毛毛虫森林 | 第4–6章 | 巨型蘑菇、烟雾、月光林地 | 对话解谜；柴郡猫首次现身地 |
| L5 | 疯帽子茶会 | 第7章 | 无尽长桌、茶具堆积、永恒下午 | 招牌场景（资源最重） |
| L6 | 红桃皇后宫殿 | 第8章 | 白玫瑰树、猩红颜料、扑克卫兵 | 涂色场景卡；文献档案富矿（判决书/砍头令） |

- H2 公爵夫人厨房（第6章：胡椒、飞锅、婴儿变猪）——毛毛虫森林线索集齐解锁
- H3 素甲鱼海岸（第9–10章：悲伤的故事、龙虾四组舞）——档案完成度 ≥60% 解锁

## 2.3 奇幻规则（梦境物理 · 8 条 → 交互设计接口）

| 规则 | 原著表现 | 转化为互动 |
|---|---|---|

| R3 逻辑错位 | 文字游戏、无答案谜语 | 谜题以"错位的逻辑"为正解 |

## 2.4 关键事件（= 梦境时间线 7 节点，直接采用初步想法）

```
01 发现白兔 → 02 进入兔子洞 → 03 第一次变大变小 → 04 遇见毛毛虫
→ 05 疯帽子茶会 → 06 红桃皇后审判 → 07 醒来
```

每个时间线节点包含：故事情节 + 插画 + 动画 + 互动小游戏（详见第 6 节 A 表）。
原著其余情节（眼泪池渡水、会议赛跑、玫瑰涂色、槌球赛、素甲鱼等）分配到**地点场景卡**与**隐藏故事**中承载，不与时间线重复。

## 2.5 象征主题（主题解析系统 · 三支柱 + 扩展槽）

| 主题 | 初步想法中的阐释 | 档案馆表达方式 |
|---|---|---|
| **成长** | 身体变化：小→大；儿童进入成人世界 | 比例滑杆贯穿全程；每章"尺寸记录"；主题页含成长曲线可视化 |
| **身份** | "我是谁？" | 旅途身份标签收集（女仆/巨人/证人/侦探……）；毛毛虫问答回放 |
| **规则** | 红桃皇后的世界：荒诞规则 | 砍头令/判决书文献集；法庭"只有荒诞能赢"的辩论玩法 |
| 扩展：时间与梦 | — | 六点钟永远不到的可交互钟表；褪色/显影视觉系统 |
| 扩展：好奇心 | — | 所有"危险操作"都被鼓励并有彩蛋 |
| 扩展：荒诞逻辑 | — | 谜题的"错误答案"往往更合逻辑 |

MVP 先做三支柱，扩展槽 V1.5 开放。

## 3.3 系统数据流

```
时间线事件 ──完成──► 解锁下一地点（地图上显影）
    │ └──产出──► 档案卡 + 时间线事件块点亮
地点页探索 ──产出──► 档案卡（人物/生物/物品/文献）+ 笑容碎片×1/地点
档案库完成度 ──► 密码门三条件之一（扑克牌/口令线索）──► 审判庭开放
人物卡"隐藏问题" ──答案线索──► 藏于文献档案与隐藏故事
碎片 ×12 ──► 柴郡猫迷宫入口开启 ──► 第 13 号档案（个人旅程卡+分享图）
```

**设计要点：**
- **双轨互锁但不卡死**：时间线推进是解锁新地点的唯一条件（保证叙事秩序）；地点内的收集不影响主线推进（不逼收集癖以外的用户）。
- **密码门是唯一"硬收集门槛"**：进审判庭需要扑克牌×4 + 时间线复原 + 人物口令——全部可在主线沿途自然获得，不回溯。
- **档案馆即元叙事**：一切 UI 皆为手稿实物——地图是墙上的挂图，档案卡是抽屉卡片，谜题簿是桌面笔记。无游戏感 HUD。
- **柴郡猫三合一**：旁白 + 提示系统 + 彩蛋触发器。提示不说"请点击 XX"，而说"要是我，就挠一挠那朵玫瑰的下巴"。

## 3.4 导航规则

- 顶部档案导航带全局常驻（六个模块一键切换）；右下角研究员徽章呼出快捷环（存档/设置/帮助）。
- 地点按时间线进度逐一显影解锁；已解锁地点任意重访，收集品状态保留。
- 每张档案卡标注出处（地点/事件），点击"返回现场"跳转对应地点锚点——驱动重访的核心钩子。

# 4. 页面结构设计

共 14 类页面/模板。（资产编号对应第 7 节。）

## 4.1 首页 · 进入兔子洞（Landing）

- **目的**：建立"这不是一本书"的第一认知；单一行动召唤。
- **看到**：全屏手稿风河岸：羊皮纸底、钢笔淡彩的巨树与树洞，标题"爱丽丝梦游仙境 / Wonderland Archive"烫金浮现。白兔剪影周期性跑入树洞，掉落一片纸屑。唯一主按钮：〔进入兔子洞〕（树洞本身就是按钮，悬停时洞口微光增强）。

# 7. 美术资产规划

## 7.1 总体美术方向（沿用 v1.1 修订稿）

- **风格锚点**：一份从维多利亚时代遗留下来的私人研究手稿。五关键词：**维多利亚手稿 · 羊皮纸 · 老式插画 · 英式庄园 · 梦境奇幻色彩**。
  - **载体是手稿**：全产品容器皆为纸——羊皮纸底、毛边、火漆印、铜版刻章、手写批注与墨渍。
  - **插画是老式插画**：维多利亚铜版画/钢笔淡彩——细密排线、手工上色、微套色偏差；人物走 19 世纪童话插画古典路线，不走现代动画造型。
  - **空间是英式庄园**：档案库的厅室是庄园藏书楼——胡桃木、黄铜、绿灯罩台灯、皮面书。
  - **色彩是梦境的突破口**：基底克制的羊皮纸暖黄+胡桃木深棕+墨黑；梦境以高饱和色从纸面渗出——柴郡猫的紫、蘑菇的荧蓝绿、玫瑰园的猩红、茶会的爱丽丝蓝。**纸是现实的，颜色是梦的**。
- **双态色彩系统**：未解锁 = 铅笔素描稿（只剩排线与纸色）；已收集 = 水彩上色完成。收集 = 亲手为手稿上色。
- **字体**：中文衬线 + 英文铜版花体标题 + 打字机等宽正文 + 手写体（爱丽丝笔记/柴郡猫批注专用）。
- **生产方式**：AI 生成底稿（统一风格提示词组：victorian manuscript / copperplate engraving / hand-colored etching / parchment texture / english manor interior / dreamlike saturated color accents）→ 人工修版 → 分层输出 → 序列帧/Lottie/shader 动效。

# 8. 技术实现建议

## 8.1 技术选型

| 层 | 选型 | 理由 |
|---|---|---|
| 框架 | React 18 + TypeScript + Vite | 页面/组件化；TS 保证数据驱动内容（地点/事件/卡片全 JSON）可维护 |
| 2D 渲染 | PixiJS（WebGL）或 Canvas 2D + CSS | 视差层、mask、粒子；小团队可用 Canvas+CSS 覆盖 80% |
| 动效 | GSAP（场景/转场/镜头）+ Framer Motion（UI/卡片/弹层） | 分工明确 |
| 物理 | Matter.js（仅 E02 坠落、L7 槌球、H2 锅碗，按需动态 import） | 不进主包 |
| 地图/长桌拖缩放 | pixi-viewport 或自研 Canvas 变换层 | L5 茶会 4 屏宽与地图共用一套 |
| 涂色 | Canvas 混合模式（multiply）+ 笔刷纹理 | L6 核心 |
| 数据层 | JSON 内容表 + Zustand 状态机；localStorage 存档（预留 IndexedDB） | 策划改文案不碰代码 |
| 国际化 | i18next（中/EN 文案表） | 档案卡双语 |
| 分享图 | Canvas 合成导出 | 终局旅程卡 |
| 部署 | 纯前端 SPA 静态部署（Vercel/GitHub Pages） | Vibe Coding 友好 |

## 8.2 2D vs 3D 划分（结论：MVP 不做 3D）

| 2D（MVP 全部） | 3D（V2.0+ 再议） |
|---|---|
| 全部场景：手稿插画+视差分层（2.5D 足够表达纵深与"纸上立体书"感） | Three.js 兔子洞自由落体 |
| 角色：序列帧/Lottie 伪骨骼 | 茶会 3D 环绕镜头 |
| 变形：morph 序列帧+shader 扭曲 | 实时形变 |
| 粒子：纸牌/落叶/雾（2D 粒子足够） | 体积雾/流体 |
| 光线玩法：mask+径向渐变 | 实时光照 |

手稿风插画的灵魂在纸面质感，引入 Three.js 会造成风格撕裂与成本爆炸。**锁定：React + GSAP + Framer Motion + PixiJS + Matter.js（按需）**。

## 8.3 性能与兼容

- 插画 WebP + 分级预载（当前地点预载下一地点）；单场景纹理 ≤8MB；长边 ≤2048px。
- 视差 ≤5 层/场景；粒子 ≤300 同屏；Matter 刚体 ≤40。
- 移动端 touch 全映射（拖/双指/长按）；陀螺仪降级为触摸偏移。
- 色觉友好模式：提示除颜色外加形状描边；字幕可常驻。
- 自动存档：收集/事件完成即写 localStorage；设"重置梦境"入口。
