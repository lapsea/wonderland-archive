# 奇境档案馆 · Wonderland Archive

《爱丽丝梦游仙境：奇境档案馆》Demo 的开源美术素材与生产文档仓库。

仓库包含两个阶段的美术资产（图片素材）以及完整的美术生产规范、风格提示词和逐图 Prompt 清单，用于统一 AI 美术生产的方向、流程与验收标准。

## 内容结构

```
.
├── docs/               # 生产文档（方案、规范、提示词、Prompt 清单）
├── art-美术资产v1/     # 第一阶段美术资产（UI、场景、角色、道具、卡片）
├── art-美术资产v2/     # 第二阶段美术资产（时间线、谜题、宫殿、茶会等）
└── README.md
```
